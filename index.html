pSZ/cuSZ

A GPU-based error-bounded lossy compressor for scientific data.

GitHub

pSZ/cuSZ is a GPU implementation of the SZ algorithm. It was the first GPU-practical framework of error-bounded lossy compression for scientific data (circa 2020), built to improve SZ's throughput on heterogeneous HPC systems. It focuses on the CUDA backend, with other GPU-parallel backends in development. The project was formerly named cuSZ, which remains the short form.

cuSZ PACT '20 ACM arXiv and cuSZ+ CLUSTER '21 IEEE arXiv

  • Basic framework: N-D Lorenzo prediction and Huffman encoding on GPU.
  • Algorithmic novelty: fully parallelized N-D Lorenzo prediction and reverse prediction.
  • Pipeline novelty: alternative route for cases with extremely "smooth" data.

cuSZ-i SC '24 IEEE arXiv and cuSZ-Hi SC '25 ACM arXiv

  • SZ3/QoZ-HPEZ pipeline on GPU: spline-interpolation-based data reconstruction with high rate-distortion capability.
  • Pipeline novelty: GPU-realistic ratio-boosting synergetic encoding stage applied to the original framework is designed (cuSZ-i).
  • Pipeline novelty: It is further discussed in cuSZ-Hi using the sub-pipeline composition by the LC framework (a research project led by Dr. Martin Burtscher), forming two presets, HiTP and HiCR, further pushing the boundary of achievable rate-distortion on GPU.

FZ-GPU · Zhang, Tian et al., '23

Prediction plus de-redundancy only, no histogram or Huffman: it prioritizes data-processing speed.

git clone --recursive https://github.com/szcompressor/cuSZ.git cusz-latest
cd cusz-latest && mkdir build && cd build
cmake .. -DPSZ_BACKEND=cuda -DPSZ_BUILD_EXAMPLES=on -DCMAKE_BUILD_TYPE=Release \
    -DCMAKE_CUDA_ARCHITECTURES="<sm>"
make -j
make install

Needs CUDA 11.4 onward, a C++17 host compiler (GCC 9 onward or any Clang), and CMake 3.18 onward. Without CMAKE_CUDA_ARCHITECTURES (or the CUDAARCHS environment variable), the build targets 75 only. 

cusz -t f32 -m r2r -e 1e-4 -i data.f32 -l 3600-1800 -z --report cr
cusz -i data.f32.cusza -x --compare data.f32 --skip write2disk

--skip write2disk checks compression quality without writing the reconstruction to disk. -p picks the pipeline, e.g. -p spl.. or -p preset:hicr. -V reports the machine it ran on. 

CUDAARCHS="<sm>" pip install -e py_ext --no-build-isolation
from psz import compress_init, decompress_init

with compress_init(data.shape) as c:  # data: a float32 CuPy array
    c.compress_process("lrz..", data, 1e-3 * c.compress_extrema(data).rng)
    header, archive = c.compress_archive()

with decompress_init(header) as dc:
    xdata = dc.decompress_process(archive)

psz is a nanobind binding that works on CuPy arrays; example/src/demo_py.ipynb walks through it.
