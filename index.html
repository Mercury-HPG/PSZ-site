pSZ/cuSZ

A GPU-based error-bounded lossy compressor for scientific data.

pSZ/cuSZ is a GPU implementation of the SZ algorithm. It was the first GPU-practical framework of error-bounded lossy compression for scientific data (circa 2020), built to improve SZ's throughput on heterogeneous HPC systems. It focuses on the CUDA backend, with other GPU-parallel backends in development. The project was formerly named cuSZ, which remains the short form.

How it works

  1. The user picks an error mode: absolute (abs), or relative to the data's value range (r2r), and an error bound.
  2. Prediction errors are quantized in units of that bound. In-range quant-codes are stored; out-of-range ones are gathered as outliers.
  3. The in-range quant-codes go through a Huffman encoder.
  4. CPU-SZ adds a DEFLATE pass to exploit repeated patterns; on the GPU, cuSZ+'s RLE plays the same role.

There are real differences between CPU-SZ and pSZ/cuSZ; the papers below carry the detail.

Variants

each trades quality, ratio, and speed differently

  • cuSZ · Tian et al., '20, '21

    The basic framework: an N-D Lorenzo predictor, a histogram, and Huffman encoding. A balanced compression ratio and quality.

  • cuSZ+ (hi-ratio) · Tian et al., '21

    A de-redundancy RLE pass ahead of Huffman, from compressibility research showing RLE wins on highly compressible data.

  • FZ-GPU · Zhang, Tian et al., '23

    Prediction plus de-redundancy only, no histogram or Huffman: it prioritizes data-processing speed.

  • cuSZ-i · Liu, Tian, Wu et al., '24

    A spline-interpolative 3-D predictor with QoZ-like methods, for substantially better reconstruction quality and compression ratio.

  • cuSZ-Hi · Wu and Pan et al., '25

    A 2-D/3-D spline predictor feeding two encoder paths, one tuned for ratio and one for throughput.

Install and run

Spack

spack install cusz
spack load cusz

Compress, then reconstruct

./bin/cusz -f32 -m r2r -e 1e-4 -i data.f32 -D parihaka -z
./bin/cusz -i data.f32.cusza -x --origin data.f32 --skip write.x

--skip write.x checks compression quality without writing the reconstruction to disk. -V reports the machine it ran on.

Fuller instructions live in the wiki (build and install, command-line use, API reference), and the supported toolchains on the doc branch.
